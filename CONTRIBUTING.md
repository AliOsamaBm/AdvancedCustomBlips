# Contributing to Advanced Custom Blips

Thank you for your interest in contributing!

---

## 📌 Before You Start

* Make sure you understand the purpose of the mod
* Keep changes focused and minimal
* Avoid breaking existing functionality

---

## 🛠 Development Setup

1. Install Microsoft Visual Studio 2022 Community
2. Install .NET Framework 4.8
3. Install latest ScriptHookVDotNet version 3.0
4. Install LemonUI
5. Install INI File Parser
6. Install NewtonSoft JSON
7. Clone the repository
8. Open the solution file in `/source/AdvancedCustomBlips/`

---

## 📋 Guidelines

* Follow existing code style and structure
* Write clear and readable code
* Avoid unnecessary complexity

---

## 🧪 Testing

Before submitting:

* Ensure the mod runs without errors
* Test adding, editing, and deleting blips
* Check performance impact
* Provide the changlog as in the format in what was added, improved, fixed, and removed

---

## 🔄 Pull Requests

* Describe what you changed and why
* Keep PRs small and focused
* Link related issues if applicable

---

## 🐛 Bug Reports

Include:

* Steps to reproduce
* Logs (`Advanced Custom Blips Log.txt` and `ScriptHookVDotNet.log`)
* Expected vs actual behavior
* GTAV version (Enhanced or Legacy)

---

## 💡 Suggestions

Feature ideas are welcome!
Open an issue and describe your idea clearly.
