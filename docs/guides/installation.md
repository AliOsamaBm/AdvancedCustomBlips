# Installation Guide (GTA V Legacy Only)

> This guide explains how to install **Advanced Custom Blips** on the **Legacy version of GTA V**.
> This mod has **NOT been tested on the Enhanced version**.

---

## 📌 Step 1 — Install Script Hook V

1. Go to:
   http://www.dev-c.com/gtav/scripthookv/

2. Download the `.zip` file  
   > ⚠️ Ignore the "for developers" option

3. Open the downloaded `.zip` file

4. Navigate to the `bin` folder

5. Extract the following files into your GTA V directory  
   (the folder where `GTA5.exe` is located):

   - `dinput8.dll`
   - `ScriptHookV.dll`
   - `xinput1_4.dll`
   - `args.txt`

---

## 📌 Step 2 — Install Script Hook V .NET (Nightly)

1. Make sure a folder named `scripts` exists in your GTA V directory  
   > If it does not exist, create it using the exact name: `scripts`

2. Go to:
   https://github.com/scripthookvdotnet/scripthookvdotnet-nightly/releases

3. Download the latest file from the **Assets** section:  
   `ScriptHookVDotNet-vX.X.X-nightly.XXX.zip`

4. Open the `.zip` file and extract the following files into your GTA V directory:

   - `ScriptHookVDotNet.asi`
   - `ScriptHookVDotNet.ini`
   - `ScriptHookVDotNet.pdb`
   - `ScriptHookVDotNet2.dll`
   - `ScriptHookVDotNet2.pdb`
   - `ScriptHookVDotNet3.dll`
   - `ScriptHookVDotNet3.pdb`

---

## 📌 Step 3 — Install .NET Framework 4.8

1. Go to:
   https://dotnet.microsoft.com/en-us/download/dotnet-framework/thank-you/net48-web-installer

2. Download and run the installer

3. Follow the installation instructions

---

## 📌 Step 4 — Install Advanced Custom Blips

1. Download the mod archive

2. Extract **all files** into the `scripts` folder inside your GTA V directory

---

## 📝 Notes

- This mod is designed for **GTA V Legacy**
- Compatibility with Enhanced version is **not guaranteed**
- If the mod does not load, check your installation carefully before reporting issues
